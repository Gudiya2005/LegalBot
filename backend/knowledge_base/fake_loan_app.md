# Fake Loan App Scam

## Description
Fake loan applications lure users with instant loans and later demand illegal fees, access personal data, or blackmail victims.

## Common Signs
- Instant loan approval.
- Excessive permissions requested.
- Threatening recovery calls.
- Illegal processing fees.
- Unknown app developers.

## Immediate Steps
1. Uninstall the fake app.
2. Revoke app permissions.
3. Block payments if any.
4. Save screenshots.
5. Report the app.

## Prevention
- Download apps only from trusted sources.
- Check reviews.
- Avoid unknown APK files.
- Verify NBFC or bank registration.
