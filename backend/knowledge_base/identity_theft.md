# Identity Theft

## Description
Identity Theft occurs when someone illegally uses another person's personal information such as Aadhaar, PAN, bank details, or identity documents.

## Common Signs
- Unknown loans.
- Unauthorized bank accounts.
- Fake SIM registration.
- Unexpected financial activity.
- Unknown online accounts.

## Immediate Steps
1. Inform your bank.
2. Block compromised documents if applicable.
3. Change passwords.
4. Monitor financial records.
5. Report identity misuse.

## Prevention
- Protect personal documents.
- Share Aadhaar or PAN only when necessary.
- Use strong passwords.
- Enable Two-Factor Authentication.
